# 澄 · 前端与动效重构（设计系统 2.0）

分支：`claude/frontend-animation-redesign-2e4f23`。基线为主目录 0.6.0 之后尚未提交的工作（动效、伪息屏、听歌喜好、曲库跳转），原样快照为本分支第一个提交，再在其上重构。

## 设计原则

1. **贴合主题**：保留并强化两套既有视觉语言，不另起炉灶。
   - **澄 · 经典**：暖纸色底、墨色文字、陶土色强调（深色为夜墨 + 琥珀）。圆角、柔和阴影、悬浮式迷你播放器、封面柔光背景——像光透过清水，呼应“澄”。
   - **终末地 · 工业**：纸白 / 枪灰、信号黄、直角模块、粗细分割线、切角按钮；动效更短、更“机械”，页头黄色定位条在进页时像信号一样延伸。
2. **动效只走合成线程**：全部转场都是 `transform` / `opacity` 的 Web Animations 或 CSS transition，主线程在渲染列表、轮询播放状态时不会卡住已经开始的动画。不永久提升图层、不做循环动画、不做全屏模糊。
3. **每个操作都有过渡，且可被打断**：新的状态总会取消它所取代的旧动画；快速连点以最后一次为准。
4. **颜色过渡自然**：颜色令牌注册为 `@property <color>`，主题、封面取色变化时整套配色在 520ms 内平滑过渡；系统状态栏 / 导航栏用同一时长和曲线在原生侧插值。
5. **减少动态效果**：系统设置或应用内开关打开时，所有移动和颜色渐变直接落到终态。

## 令牌

| 类别 | 令牌 |
| --- | --- |
| 颜色 | `--m3x-bg / fg / muted / surface / raised / border / accent / on-accent`（注册属性，可插值），派生 `accent-soft / hairline / state`（`color-mix`） |
| 形状 | `--r-xs 4 / sm 8 / md 12 / lg 16 / xl 24`，终末地全部为 0 |
| 时长 | 按压 90ms · 140 · 220 · 300 · 420 · 颜色 520ms |

弹簧曲线由阻尼弹簧阶跃响应离线采样为 CSS `linear()`（Chromium 113+）。

## 动效清单

| 操作 | 过渡 |
| --- | --- |
| 底部导航切换 | 指示块弹簧滑动；页面按方向共享 X 轴滑入 / 淡出 |
| 进入子页（设置、统计、收藏、歌单、队列） | 新页从右侧推入，父页左移淡出；返回时反向，子页盖在上层滑出 |
| 点歌曲 / 迷你播放器进入播放页 | 列表或迷你播放器里的封面**飞行**到大封面位置；其余控件分层上浮 |
| 播放页 ↔ 歌词 | 缩放淡入淡出（进入时内容由 1.04 收拢） |
| 离开 / 回到播放页 | 迷你播放器下沉停靠 / 弹簧浮起 |
| 切歌 | 旧封面向反方向滑出缩小，新封面弹簧滑入；曲名、歌手、专辑依次错位淡入；柔光背景交叉淡化；封面取色整体渐变 |
| 播放 / 暂停、播放模式 | 图标旋转缩放变形 |
| 收藏 | 爱心弹跳 + 一圈扩散波纹 |
| 曲库筛选、分组进入、列表 / 网格切换 | 下划线 / 分段滑块弹簧移动；列表或网格卡片错位上浮（网格按行错位） |
| 搜索输入 | 结果安静淡入，不做逐行编排 |
| 抽屉（声音与输出、歌曲菜单等） | 无过冲弹簧升起、遮罩淡入、内容错位出现；加速下沉关闭；按住把手 / 标题下拉可拖拽关闭，松手按距离和速度决定关闭或回弹 |
| 提示条 | 弹簧上浮出现，换文案时轻弹，淡出下沉 |
| 开关、滑块 | 拇指弹簧移动；进度圆点按下放大 |
| 播放进度 | 进度条和圆点用合成层 `transform` 线性跟随，跳转时柔和滑到新位置 |
| 明暗 / 主题 / 布局切换 | 整页快照交叉淡化（View Transitions），避免逐元素抖动 |
| 统计页 | 柱状图、时段条、排行比例条从基线生长 |
| 伪息屏 | 从黑场淡入，封面缓缓落定 |
| 歌词跟随 | 可打断的减速滚动，当前句放大点亮 |

## 性能手段

- **页面不再 `display:none`**：隐藏页改用 `content-visibility: hidden`，保留布局与滚动位置，切页时不必整页重新排版。`[hidden]` 属性语义不变，现有脚本和测试照常判断。
- **曲库选择结果缓存**：4,000+ 首歌曲的筛选、排序与喜好排除按条件记忆，导航与普通重绘不再重复过滤、排序和序列化。
- 列表入场最多编排前 14 项；封面柔光用 40×40 画布预先模糊后放大，静态合成，不做实时滤镜。

- **两帧交接**：切页时第一帧只提交旧页面的离场动画，下一帧再解锁新页面；新页面的样式、绘制与光栅在离场动画进行中完成。
- **切歌少阻塞**：隐式存盘（播放/暂停/进度/导航）在队列未变时合并，转场结束后空闲执行；切歌后回读 4,000+ 首队列推迟 650ms；原生侧进度与历史两次 70KB 设置读写合并为一次并推迟 700ms。队列变化和需要报错的保存仍同步执行。
- **系统栏同步渐变**：`appearance-bars` 携带时长，原生用 `ArgbEvaluator` 插值状态栏 / 导航栏颜色。
- 终末地与经典的底色沿用 0.6.0 真机审阅过的色值。

## 真机测量（Shanling M3X · Android 7.1.1 · WebView 119 · 4,160 首）

DevTools trace（临时可调试构建，测完已恢复为 `BuildConfig.DEBUG`），以“切到我的”为例：

| 阶段 | 改前 | 改后 |
| --- | --- | --- |
| 点击处理 + render（JS） | 133ms（冷）/ 47ms（热） | 20–38ms |
| 新页面样式重算 | 65–133ms | 约 20–25ms |
| 首帧后的转场帧间隔 | — | 约 16–18ms（60fps） |

真实触摸点击底部导航，3 轮 × 3 页，`dumpsys gfxinfo framestats`（每组最近 120 帧）：

| 指标 | 原版 | 新版 |
| --- | --- | --- |
| 渲染帧数 | 约 107（多数切页无过渡） | 约 231（每次切页约 25 帧过渡） |
| 超过 33ms 的帧 | 33 / 107（约 31%） | 21–22 / 120（约 18%） |
| p50 / p95 | 15–17ms / 53–57ms | 19ms / 81–85ms |

切歌（DevTools 计时）：JS 同步阻塞 266ms → 155–190ms。

**尚未达到的部分（如实记录）**

- 进入新页面的第一帧仍有约 60–90ms 停顿：主要是 Adreno 505 为新页面执行 GPU 光栅（文字字形占约一半），这是 p95 偏高的原因；停顿之后动画保持 60fps。
- 切歌时 Media3 / ExoPlayer 的两次监听分发各约 250ms，在 Android UI 线程上执行，原版同样存在，会冻住切歌动画中段。属于原生播放链路，本次未改动，列为后续项。
- `UiMotionDeviceTest#testMotionAndPlayback` 在“等待歌词行数 >3”处失败；原版安装包同样失败，因为当前歌曲没有本地歌词。该步之前的导航、抽屉、重开取消关闭、最后一次导航生效、唯一可见页面、导航期间无音频欠载、真实切歌封面一致均通过。
- `UiPerformanceTest`、`UiAppearanceCaptureTest`（131 张物理截图，`captures/appearance-20261105-011145/`）、JVM 单元测试及全部本地 JS 测试通过。
- 帧率探针 `UiFrameProbeTest` 为本次新增；其首帧数值受 `dumpsys` 调用干扰偏大，只用于同条件前后对比。
